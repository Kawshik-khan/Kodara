# KODARA PROJECT OVERVIEW

## 1. Product Summary

**Kodara** is a bilingual interactive, browser-based software-engineering learning environment designed to take developers from surface-level syntax memorization to deep architectural mastery.

* **Core Philosophy**: "Understand how software works."
* **Language Foundation**: Native Bangla (`bn`) default paired with industry-standard English programming syntax and technical vocabulary.
* **Central Learning Loop**:
  ```text
  Learn
  → Understand
  → Visualize
  → Build
  → Execute
  → Trace
  → Inspect
  → Break
  → Debug
  → Verify
  → Master
  → Build
  ```

## 2. Product Category

Bilingual Interactive Software-Engineering Learning & Simulation Environment.

Unlike static documentation, video tutorial platforms, or simple coding sandboxes, Kodara combines:
1. **Bilingual Native Education**: Natural, conversational Bangla conceptual explanations paired with industry-standard English terminology and English code.
2. **Interactive Mental Models**: Visualizing the inner mechanics of code, memory, scope, and system topologies.
3. **Deterministic Execution Tracing**: Language runtime tracing showing variable allocations, call stacks, references, closures, promises, and event loop transitions step-by-step.
4. **"Break It" Debugging Labs**: Purposefully injected failure scenarios (memory leaks, race conditions, stale closures, cascade failures, cache stampedes) where learners diagnose root causes.
5. **Graph-Based Mastery**: Non-linear prerequisite graphs that track competency through multi-signal evidence rather than simple page views.
6. **AI-Assisted Socratic Tutoring**: Context-aware AI tutoring that guides learners with incremental hints in their preferred language rather than handing over canned answers.

## 3. Target Learners

* **Computer Science & Bootcamp Students**: Seeking intuitive visual models for runtime execution, data structures, and type systems.
* **Self-Taught Developers**: Bridging the gap between building toy projects and understanding computer science fundamentals and production system design.
* **Junior & Mid-Level Developers**: Deepening their mental models of TypeScript internals, Python runtime nuances, and React rendering pipelines.
* **Developers Changing Stacks**: Quickly grasping the nuances of a new language/paradigm by comparing abstractions and execution models.
* **Experienced Engineers Leveling Up**: Mastering Distributed System Design, Failure Modes, and Modern AI Engineering (LLM orchestration, RAG, tool calling).
* **Technical Interview Candidates**: Preparing for rigorous systems and coding interviews through interactive tracing and architecture simulation.

## 4. Learning Tracks

Kodara offers five comprehensive engineering tracks:

1. **TypeScript**:
   - JavaScript Runtime Foundations (variables, primitives, heap objects, references, call stack, scope, closures, event loop)
   - TypeScript Fundamentals (annotations, inference, structural typing, interfaces, type aliases, tuples, unions)
   - Advanced Type System (type narrowing, guards, intersections, literal types, generics, conditional types, mapped types, template literals)
2. **Python**:
   - Python Execution Engine (bytecode compilation, Python virtual machine, references, mutability vs immutability)
   - Scope & Closures (LEGB rule, global/nonlocal, decorators)
   - Advanced Python (iterators, generators, context managers, descriptors, asyncio event loop)
3. **React**:
   - Component Mental Model (pure functions, JSX compilation, virtual DOM)
   - React Execution Pipeline (render phase, reconciliation/diffing, commit phase, layout/paint)
   - State & Lifecycle (hooks mechanics, closures in hooks, fiber tree, concurrent features)
   - Performance & Debugging (unnecessary renders, memoization tradeoffs, profiling)
4. **System Design**:
   - Distributed Building Blocks (load balancers, reverse proxies, caching layers, queues, databases, object stores)
   - Architectural Patterns (event-driven architecture, CQRS, sharding, replication, consensus)
   - Interactive Architecture Lab (live node-graph simulation with traffic generation, latency injection, node failure, cache stampede)
5. **AI Engineering**:
   - LLM Fundamentals (tokens, context windows, sampling parameters, embeddings, vector space)
   - Retrieval Augmented Generation (chunking strategies, vector search, hybrid retrieval, re-ranking)
   - Agents & Tool Execution (function calling, execution loops, memory management, structured outputs, prompt injection defenses)

## 5. Key Differentiators

| Traditional Platforms | Kodara Platform |
| :--- | :--- |
| Passive video watching or reading text | Interactive theory paired with immediate visual manipulation |
| Black-box code execution (only output shown) | Transparent runtime execution tracing (stack, heap, scope, events) |
| "Write code to pass tests" | "Build it manually → Observe execution → Break it → Debug it → Master it" |
| Artificial quiz scores determine completion | Evidence-based mastery tracking across execution, challenges, and debugging |
| Isolated syntax snippets | Full mental model connecting code to runtime to distributed architecture |
| Generic AI chatbots providing direct code | Socratic AI Tutor grounded in AST, runtime trace, and learner history |
